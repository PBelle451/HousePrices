Projeto de Ciência de Dados que usa os algoritmos de Machine Learning de Regressão Linear e Random Forest Regressor
O funcionamento do código é que o dataset é lido, a análise exploratória dos dados é feita, a distribuição do preço dos imóveis é demonstrada num histograma 
e um mapa de calor de correlação entre variáveis é mostrado.
Após isso, os dados para a regressão são separados para teste e treinamento
Os dados são alocados nos algoritmos de Regressão Linear e Random Forest Regressor e após sua execução, os dados são demonstrados
